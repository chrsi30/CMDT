#cmdt

A Mathematical Model of Dietary Lipid Absorption and Postprandial Chylomicron Dynamics

Authors:
Christian Simonsson1,2,† , Oscar Silfvergren1,3,† , Henrik Podéus1, Kajsa Tunedal3,4, William Lövfors1, Karin Stenkula2, Elin Nyman1, Gunnar Cedersund1,3*

This repository has all the scripts necessary to reproduce the results presented in the paper. To run the scripts will require additonal toolboxes:
Simulation: Systems biology toolbox: https://academic.oup.com/bioinformatics/article/22/4/514/183389, download: https://iqmtools.intiquan.com/ 
Parameter estimation: MEIGO: an open-source software suite based on metaheuristics for global optimization in systems biology and bioinformatics, https://pmc.ncbi.nlm.nih.gov/articles/PMC4025564/
All analysis was done using MATLAB 2023b.

In this repository the main script will allow you to control what to run. When running the main.m script a menu will prompt you to choose:
1. Plot supplementary
2. Plot Figure 2 and Figure 3
3. Plot Figure 4
4. Run the parameter estimation
